## 1. 과거 마크가격과 베이시스

Tardis는 BitMEX 자료 수집 시작일을 2019년 3월 30일로 명시하고, 매월 첫날의 CSV를 공개합니다. 해당 월초 33일 전체에서 전일부터 보유했거나 당일 거래한 모든 계약을 선택하고 BTC/USD 환산용 XBTUSD를 추가했습니다. 특이한 베이시스가 나온 날만 골라낸 표본이 아닙니다. [제공자 자료 범위](https://docs.tardis.dev/historical-data-details/bitmex).

`derivative_ticker`에는 마크·지수·마지막 거래 가격과 거래소·수집 시각이 구분되어 있습니다. 거래소 피드를 제3자가 보관한 자료입니다. 펀딩 필드는 예정된 사건을 나타내므로 실제 계좌에 부과된 펀딩 기록을 대체하지 않았습니다. [제공자 스키마](https://docs.tardis.dev/downloadable-csv-files/data-types.md).

매분 경계에서 거래소 시각과 수집 시각 중 늦은 시각이 경계보다 앞선 마지막 행만 사용합니다. 거래소 시각 기준 300초보다 오래된 기록은 제외했습니다. 미래 관측을 가져오지 않으며 포트폴리오 관측 1개는 결측으로 남습니다. 최신성은 행 단위 검사입니다. 마지막 거래 가격 등 개별 필드가 실제로 최근 갱신되었다는 의미까지는 아닙니다. 일 종료는 v0.4와 같이 다음 UTC 자정 직전입니다.

측정 베이시스는 `10,000 × (마크가격 / 지수가격 − 1)` bp입니다. 업데이트가 잦은 시간을 과도하게 반영하지 않도록 같은 간격의 분 단위 통계를 사용합니다. 연율화하지 않았습니다. BTC 표시 교차 계약과 과거 USDT 표시 콴토도 각 계약의 표시 통화와 지수를 사용하며, 후자의 정산 통화는 v0.4 사양에 따라 BTC입니다. BitMEX가 미실현손익·청산에 사용하는 마크가격과 실제 거래가격을 구분하므로 종가를 마크가격으로 바꾸어 부르지 않았습니다. [무기한 계약 설명](https://www.bitmex.com/app/perpetualContractsGuide).

| --- | --- | ---: | ---: |
| 2020-02-01 | XBTH20 | +2.2763% | +2.1561%~+2.4326% |
| 2021-01-01 | XRPH21 | −16.9788% | −17.6010%~−15.1349% |

큰 XRP·ETH 스프레드를 이상치로 삭제하지 않았습니다. XRPH21은 XRP/BTC 선형 선물이고 ETHUSDM21은 ETH/USD 콴토 선물입니다. 지급 구조가 다르므로 같은 캐리 수익률로 취급하거나 무위험 차익거래의 증거로 해석할 수 없습니다. XRP/BTC 계약의 정체는 당시 상장 공지에서도 확인됩니다. [2021년 1분기 상장 공지](https://www.bitmex.com/blog/q1-2021-quarterly-futures-listings).

![과거 베이시스와 평가 차이](figures/historical_basis.png)

**2021년 6월 1일 UTC 종료 시점**의 복원 평가자산은 기록된 마크가격을 적용하면 **888.85524200 BTC**, v0.4 현물 기준가격을 적용하면 **909.19805707 BTC**입니다. 차이는 **−20.34281507 BTC**입니다. 여기에는 파생상품 베이시스뿐 아니라 당시 거래소 지수와 Coin Metrics 기준가격의 차이도 들어가므로 순수 베이시스 손익으로 부르지 않습니다. 별도의 동일 시각 마크·계약 지수 비교에서는 현금과 BTC 환산가격을 고정하고 파생상품 가격만 바꿉니다. 이 방식의 표본 내 최대 포트폴리오 평가 차이 절댓값은 역시 6월 1일의 약 **922,926 USD**입니다.

33개 표본 날짜에는 원본에 날짜가 기재된 입출금이 없어 하루 시작·종료 입출금 가정의 차이가 없습니다. 그래도 평가에는 수량·현금 복원, 수집 품질, 분 단위 표본이라는 전제가 남습니다. 마진 방식, 유지증거금, 실제 청산 처분가치, 분 사이 최대 위험은 알 수 없습니다. 월초 마크가격을 날짜 사이에 보간해 연속 NAV로 만들지 않았습니다.

## 2. 장중 최대 노출 복원

모든 체결과 만기 정산을 순서대로 반영합니다. 펀딩은 수량 대신 현금을 바꿉니다. 동일 주문·시각·방향 묶음은 기존 회계 규칙을 따르며, 포트폴리오 경로에는 한 시각의 계약별 변화를 함께 적용합니다. 동일 시각에 반대 방향이 기록된 3개 지점은 별도 표로 남겼습니다. 임의의 세부 순서를 만들고 그 중간값을 확정된 최대치로 주장하지 않습니다.

BTC 역선물의 USD 액면은 계약 수량에서 직접 구할 수 있습니다. 절대 합계는 `Σ |q|`, 순 액면은 `Σ q`입니다. BTC 가격 가정이 필요하지 않습니다. 거래 없는 날도 전일 수량을 이어받습니다. 롱·숏·중립 시간은 주문 횟수가 아니라 상태 사이의 실제 시간으로 계산하며 매일 합계가 24시간입니다.

동일 시각 사건 반영 후 BTC 절대 액면 합계의 최대치는 **2021년 7월 28일 16:12:29.993437 UTC의 123,345,200 USD**입니다.

| 계약 | 포지션 | BTC 절대 액면 합계 기여 |
| --- | ---: | ---: |
| XBTUSD | −83,345,200 | 83,345,200 USD |
| XBTU21 | +40,000,000 | 40,000,000 USD |

BTC 순 액면은 **−43,345,200 USD**이며, ETHUSD **300,379계약 숏**도 함께 있습니다. BTC 두 계약은 일부 상쇄되지만 베이시스·만기 위험이 남고, BTC 현금까지 포함하면 달러 가격 민감도가 다시 달라집니다. 이 시점의 수량은 원본 체결·정산에서 독립적으로 합산해 검증했습니다. [원본 기반 최대 시점 수량](../results/extended_research/headline_peak_source_inventory.csv).

**1,398일 중 792일**은 장중 BTC 절대 액면 최대치가 일 종료 수량보다 큽니다. 일 종료 절대 액면 합계의 최대는 115,169,400 USD로 장중 기록보다 작습니다. **2021년 5월 19일**에는 05:02:14.013175 UTC에 **40,702,992계약 롱**, 이후 **30,466,395계약 숏**까지 도달하지만 종료 때는 **4,981계약 숏**만 남습니다. 종료 수량이 거의 0이라는 이유로 당일 위험이 작았다고 판단할 수 없습니다.

![장중 수량과 마감 수량](figures/intraday_exposure.png)

서로 다른 자산의 계약 수량은 바로 더할 수 없습니다. 전체 기간 비교에는 **전일** BTC·알트·USDT 기준가격을 당일 내내 고정하고 수량 변경 때마다 계약 노출을 다시 계산했습니다. 당일의 미래 종가를 사용하는 문제를 피하기 위한 설계입니다. 이 기준의 최대 절대 노출 합은 **2021년 8월 10일 약 1억 8,836만 USD**입니다. 고정 가격에서 수량 변화를 측정한 값이며 실제 장중 시장가치 최대치가 아닙니다. UP 옵션에 가격이 없는 관련 관측은 평가 불가로 남기고 위험을 0으로 대체하지 않았습니다.

월초 실제 마크가격 표본의 시장가치 노출은 별도로 제공합니다. 어느 쪽도 실제 계좌 레버리지나 청산까지의 거리를 확정하지 않습니다. 이를 위해서는 당시 마진·위험 한도와 계좌 상태가 필요합니다. ## 3. 입출금과 조건부 수익률

입출금은 외부 자본 흐름이고, 거래 실현손익·수수료·펀딩은 내부 성과입니다. 출금으로 계좌 자산이 줄어도 거래 손실이라는 뜻은 아닙니다. 출금 이후 자금의 투자 성과는 제공 계좌 범위 밖이므로 추정하지 않습니다.

일별 Modified Dietz 시나리오는 다음과 같습니다.

```text
r = (종료 평가자산 − 시작 평가자산 − F) / (시작 평가자산 + w × F)
w = 하루 시작 1, 중간 0.5, 종료 0
```

`F`는 입금이면 양수, 출금이면 음수입니다. BTC 흐름은 원본 금액을 유지합니다. USD 시나리오의 흐름 환산에는 시작 가정일 때 전일 BTC 기준가격, 중간 가정일 때 전일·당일 평균, 종료 가정일 때 당일 기준가격을 씁니다. 같은 날짜의 흐름에는 같은 시각 가정을 적용합니다. 복원된 실제 시각이 아니라 민감도 분석이며 평균 가격도 관측된 정오 환율이 아닙니다.

시간가중 수익률은 외부 흐름 전후의 평가가 필요하고, Dietz 근사로 누락된 당시 평가를 복원할 수는 없습니다. 방법론 참고는 [GIPS 핸드북](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)이며, 본 연구가 GIPS를 준수한 성과 보고라는 주장은 하지 않습니다.

아래는 유효 일별 Dietz 값을 기하 연결한 연간 결과입니다. **모두 v0.4 현물 기준 평가자산**을 사용하며 드문 월초 마크가격 표본을 끼워 넣지 않았습니다. 검증된 실제 투자 성과가 아닌 조건부 연구 수치입니다. 가정 사이 차이는 신뢰구간이나 실제 수익률의 상·하한이 아닙니다. 마크가격 오차, 장중 입출금 시각과 환율 경로에 따라 실제 결과가 범위 밖일 수 있습니다.

| 연도 | BTC 수익률, 종료~시작 시각 가정 | USD 수익률, 종료~시작 시각 가정 |
| --- | ---: | ---: |
| 2018년 부분 관측 구간 | 산출 불가 | 산출 불가 |
| 2019 | +1,255.13%~+1,344.73% | +2,534.18%~+2,708.35% |
| 2020 | +329.86%~+345.65% | +1,640.62%~+1,704.54% |
| 2021 | +679.57%~+683.72% | +1,145.14%~+1,151.76% |

이 큰 값에는 모델상 자본 규모, 상당한 출금과 가격 변화가 반영됩니다. 총실현이익을 총입금으로 나누는 방식으로 검증할 수 없습니다. BTC와 USD는 표시 통화가 다른 질문이며, USD에는 BTC 담보의 환산 효과도 포함됩니다.

![입출금 시각에 따른 조건부 수익률](figures/conditional_returns.png)

2018년에는 유효 자본이 0 이하인 구간, 4월 27~28일 출금 날짜의 불확실성, 5월 3일 옵션 평가 결측으로 연결이 끊어집니다. 종료 평가가 없으면 다음 날 시작 평가도 없으므로 그날 역시 유효 수익률이 아닙니다. 월·연간 연결에서 이런 날짜를 건너뛰지 않고, 공백 이후에는 별도의 유효 구간을 시작합니다. **전체 기간 연결 수익률, CAGR, 샤프지수는 산출하지 않았습니다.**

백분율 수익률을 만들지 않고도 조건부 BTC 금액 항등식은 확인할 수 있습니다.

```text
종료 기준 평가자산 795.40103509
+ 출금 2,814.54321713 − 입금 14.48925714
= 입출금 조정 계좌 이익 3,595.45499508 BTC
```

종료 미실현손익을 포함한 제공 계좌 범위의 금액입니다. 거래자의 현재 순자산이나 출금 자금의 이후 성과가 아닙니다. [일별 계산 항목](../results/extended_research/conditional_daily_returns.csv), [월·연간 결과](../results/extended_research/conditional_period_returns.csv), [유효 연결 구간](../results/extended_research/conditional_return_segments.csv), [원본 입출금](../results/extended_research/external_cash_flows.csv).

## 4. 재현과 추가로 필요한 근거

저장된 v0.1~v0.4 분석 이후 프로젝트 루트에서 실행합니다.

```text
python scripts/research_events.py
python scripts/mark_sample_analysis.py
python scripts/intraday_behavior.py
python scripts/flow_adjusted_returns.py
python scripts/extended_figures.py
python -m unittest discover -s tests -v
python scripts/verify_extended_research.py
```

표본이 로컬에 있으면 분석은 오프라인으로 실행됩니다. 제공자 원본 압축파일이 없는 체크아웃에서는 `research_events.py` 이후 `python scripts/fetch_historical_marks.py`를 실행합니다. URL·수집 시각·해시를 기록하고 성공한 파일을 재사용하기 전에 해시를 확인합니다. 제공자 원본과 대형 사건 캐시는 Git 제외 대상으로 두었습니다. 공개 다운로드 가능 여부가 재배포 권리를 확정하는 것은 아닙니다. 원본 계좌 파일과 이전 시장 스냅샷은 변경하지 않았습니다.

검증에는 원본 해시, 계약별 현금·수량·원가, v0.4의 모든 일별 수량, 체결·주문 수 보존, 펀딩 처리, 원본 기반 최대 시점, 가격 가용 시각, 베이시스 기여 합계, 현금흐름 공식과 결측 전파가 포함됩니다. [검증 결과](../results/extended_research/validation.json).

연속 마크가격 성과를 위해서는 모든 보유 계약·날짜의 마크·지수가 필요하며, 특히 2018년, 입출금 날짜, 연말 경계와 큰 손실일이 우선입니다. 정확한 외부 흐름 처리 시각은 별개의 불확실성을 해소합니다. 유지증거금 여유에는 추가로 마진·위험 한도 이력이 필요합니다. 높은 수익률이나 회계 일치만으로 이 자료를 대신할 수 없습니다.
